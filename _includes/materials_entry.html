The one rule, learned by breaking every cohort site that had a nested release: read the node as `include.entry` throughout, and never copy it into a local name with an assign or capture tag. Both write to Liquid's OUTERMOST scope, so a recursive call overwrites its own caller's node, never reaches a leaf, and Liquid aborts the whole page with "Nesting too deep" on data three levels deep. `include.entry` is scoped per invocation, which is why this works. That also means the file-count span below stays duplicated rather than captured, and that a leaf's fields are passed to `file_link.html` inline. That include carries the same rule - no assign, no capture - for exactly this reason. A directory is not sent through it: what its name opens is a GitHub listing, which never has a hosted copy. {% endcomment %}
