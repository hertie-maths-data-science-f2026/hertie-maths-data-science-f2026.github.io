Both Edit rows are written here DISABLED, by one loop, with the reason Liquid can give (`_includes/edit_why.html`, the one place the format is tested; each row also carries the format answer as `data-edit-why`). They depend on WHO is reading, which a public page cannot know, so `_includes/open_in.html` replaces them from the reader's saved profile, reading `data-edit-why` rather than testing the format again: live where it can build the URL (the editor row named for the reader's editor), otherwise with the exact reason.
