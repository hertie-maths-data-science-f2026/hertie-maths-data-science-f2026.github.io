Written by the DSL course sync from templates/site/ in the toolkit; every sync rewrites it. {%- endcomment -%} {% comment %} The quiet set-up line, and the one script on this site: the `online` and `local` buttons that finish the row of controls beside a file link, opening the same file in the student's own fork or their own clone. Half of that row is written in Liquid, by `file_link.html`, which knows the URLs without being told: `source` (the file's home on GitHub) and, where the site hosts a rendered copy, `render`. The other half cannot be: it depends on WHO is reading, and the settings that say so live in the reader's own browser (/profile/ writes them), because the site is one public page for the whole cohort. No profile, no `online` and no `local`. `_layouts/default.html` belongs to the shared theme, so there is no to put this in: a body-inline script is the only place it can go, which is why it is small and loads nothing, and why it is included once per page rather than once per list. It parses the SOURCE GitHub URL off the rendered page - the shape dsl_course/site.py `_gh_url` writes, so the two change together - rather than being handed a parallel set of fields to keep true. The one thing no URL carries is an assignment's repo SHAPE, which arrives as a data attribute: reading it off the sentence that prints it would break the day that sentence is reworded. {% endcomment %}
