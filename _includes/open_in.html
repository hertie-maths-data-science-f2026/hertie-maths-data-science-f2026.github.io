Written by the DSL course sync from templates/site/ in the toolkit; every sync rewrites it. {%- endcomment -%} {% comment %} The quiet set-up line, and the one script on this site: the two Edit rows of the menu beside a file link - `Edit in browser` and `Edit in ` - opening the same file in the student's own fork or their own clone, for the files of the materials repo /profile/ sets up (the first of `site.data.materials.repos`), the only repo it forks and clones. It also closes those menus: on an outside click, on Escape, and when another one opens. Every menu is one list of one-line rows - `View here` (only for a file the site hosts a copy of), `View on GitHub`, a hairline, `Edit in browser`, `Edit in ` - each with a short status on the right; an Edit row this file lacks is greyed with the reason as that status. `file_link.html` writes them in Liquid, which knows the View URLs without being told, and writes both Edit rows disabled. Those cannot be decided there: they depend on WHO is reading, and the settings that say so live in the reader's own browser (/profile/ writes them), because the site is one public page for the whole semester. This script replaces them: live where it can build the URL ("your fork", "your clone"), else greyed with why - "not an editable format", "not in your copy" (a file of any other repo), or "set up in Profile" (`Edit in browser` needs the reader's handle for their fork, the editor row their folder). `_layouts/default.html` belongs to the shared theme, so there is no to put this in: a body-inline script is the only place it can go, which is why it is small and loads nothing, and why it is included once per page rather than once per list. It parses the SOURCE GitHub URL off the rendered page - the shape `dsl_course/site_repo.py` `gh_url` writes, so the two change together - rather than being handed a parallel set of fields to keep true. The one thing no URL carries is an assignment's repo SHAPE, which arrives as a data attribute: reading it off the sentence that prints it would break the day that sentence is reworded. {% endcomment %}
