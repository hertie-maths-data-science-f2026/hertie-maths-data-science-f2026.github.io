The order is the same everywhere and is the point of this file existing: 1. heading - the ordinal ("Session 3") and, when the schedule declares one, the name 2. body - the learning objectives, then whatever the page passes as `extra` (Readings passes the citation list) 3. links - the files, last. They used to sit up beside the heading, where they crowded the title and made the description read as an afterthought. `include.section` is the singular section noun ("lecture", "lab", "reading") that selects which of the entry's links belong to this page, matched against each link's own `section` field. A row carries the links of every section that released into it, so the filter is what keeps a reading off the Lectures page. It used to be a prefix on the link NAME, which had to be stripped again here for display and was showing raw wherever something rendered a name without stripping it. {%- endcomment -%} {%- assign entry = include.entry -%}
